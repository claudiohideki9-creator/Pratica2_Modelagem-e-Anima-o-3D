# Briefing — Sol Alto

**Cliente:** Sol Alto (marca fictícia)  
**Segmento:** Protetor solar  
**Campanha:** Verão “Reaplique!”  
**Público:** Frequentadores de praia, 18–30 anos  
**Objetivo:** lembrar o público de reaplicar o protetor solar.  
**Tom:** leve, praiano, jovem e não infantil.  
**Restrição:** não mostrar pele queimada de forma realista e não coletar dados pessoais.  
**Integração escolhida:** reaplicar o produto recarrega a barra de proteção dentro do jogo.
